# System 1 offline eval (2026-10-10)

Generated by `node eval/run-eval.mjs --models minilm,bge-small --write-calibration`.

## Setup

- Golden set: 137 synthetic LinkedIn-style posts (23 food, 9 food_borderline, 16 false_friend, 77 topic, 12 noise) plus 7 posts from the user's export (held out, never used for fitting).
- Labels per prompt: restaurant 23 yes / 9 borderline; coding 8 yes / 1 borderline; jobs 7 yes / 2 borderline; immigration 7 yes / 2 borderline; climate 7 yes / 4 borderline. Borderline posts are excluded from AUROC, ECE, precision and recall but count toward escalation rates.
- Text: lib/decision/state.js normalizeForDecision, chunks of at most 800 characters at sentence boundaries, max-pooled similarity over chunks. Background corpus: 64 neutral posts (trim 0.1 each end, std floor 0.02).
- Embeddings: q8 ONNX on onnxruntime-web 1.22.0-dev.20250306-ccf8fdd9ea (wasm, the extension's runtime), one text per inference call (deterministic; matches the browser parity test).
- Every matches_prompt number below is leave-one-prompt-out (LOPO): recipe choice, Platt fit and escalation floor come from the other four prompts. Tag numbers are 5-fold cross-validated over posts.

Query recipes (cleaned = lib/decision/questions.js cleanPrompt; the expansion is a fixed text standing in for an on-device LLM expansion):

| prompt | raw | cleaned | expansion (C/D) |
|---|---|---|---|
| restaurant | find me restaurant and 5 star quality food posts. I am fascinated by michelin star cooking | restaurant and 5 star quality food; michelin star cooking | restaurants, chefs, fine dining, Michelin-starred cuisine, tasting menus and high-quality food |
| coding | AI tools that help with coding | AI tools that help with coding | AI coding assistants, code generation, AI pair programming and developer tools that write, review or test code |
| jobs | remote software engineering jobs | remote software engineering jobs | job openings for remote software engineers and developers, hiring for remote engineering roles |
| immigration | visa and immigration updates for tech workers | visa and immigration updates for tech workers | work visas, H-1B, green cards, Blue Card, work permits and immigration rule changes affecting software engineers and tech workers |
| climate | climate and extreme weather news | climate and extreme weather news | climate change, global warming, heatwaves, hurricanes, floods, droughts, wildfires and extreme weather events |

- A: raw prompt. B: max z over raw and cleaned. C: cleaned + expansion. D: max z over raw, cleaned and cleaned + expansion.

## Notes

- q8 models quantize activations per inference call, so a vector depends on the other texts in its batch (see the cos(batched, single) column). The calibration and eval/reference-vectors.json use one text per call, as the offscreen host does.
- The vectors come from onnxruntime-web's wasm backend running in Node with the wasm file the extension bundles, so they are the vectors the offscreen host computes (e2e/parity.spec.mjs). onnxruntime-node's native int8 kernels differ for a few percent of texts (cosine about 0.997); `S1_EVAL_RUNTIME=node` selects them.
- One Platt (a, b) on background z-scores transfers across prompts in ranking (AUROC near 1 everywhere) but not always in level: compare the P/R @0.5 column per held-out prompt. Adding the raw cosine as a second feature did not fix this in a LOPO check, so the calibration stays one-feature; escalation of the uncertain band recovers part of the gap.
- The `none` option of primary_tag rarely wins for social noise; the prefilter (isSocialNoise) has to remove it before System 1.
- The golden set is synthetic and small (borderline items excluded), so every number has wide error bars (one tag-coverage post is 1.3 points); the private export set has 7 items. The same author wrote the golden posts, the background corpus and the prompt expansions.
