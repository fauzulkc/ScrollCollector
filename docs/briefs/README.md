# Briefs: the Bar Raiser's findings

**Kept by the ⚖️ Bar Raiser seat** (`docs/team/bar-raiser.md`). Each finding, review pass or premortem
is one file in this folder, carrying the pasted measurement at a named commit, the blast radius, the
fix, the owning seat, the gate or decision it blocks, and what was not verified; this README lists each
file in one dated line. A fixed finding has its operative line corrected in place with the record
appended. Findings are not decisions: rulings stay in `docs/DECISIONS.md`. No findings are recorded yet.
